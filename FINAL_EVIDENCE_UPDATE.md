# Cubi final evidence update

This update adds learning evidence beyond the selected university programme.

## Added

- Four-step onboarding: Education → Extra learning → Career → Review.
- Project drag-and-drop scanner on onboarding and in the dashboard.
- Local scanning of readable source-code and text files using transparent keyword rules.
- Filename and user-description analysis for ZIP, PDF and DOCX files in the demo.
- User confirmation of detected project skills before they affect the profile.
- Manual self-study form with provider, format, link, progress, hours, mastery and optional assessment score.
- Relevance and estimated skill-improvement scores.
- New **Additional Updates** navigation tab with:
  - My updates
  - System suggestions
- Confirmed evidence updates skill levels, confidence, evidence lists and relevant career-tree steps.
- Evidence summary above the career tree.
- English, Vietnamese and Dutch translations for the new interface.

## Scoring interpretation

- **Relevance** estimates how strongly the linked skills align with the current target skill map and job-demand weights.
- **Skill improvement** estimates likely evidence strength using completion, time spent, mastery, assessment and detected project signals.

Scores are heuristic demo estimates, not formal qualifications or verified competency assessments.

## Privacy in this prototype

Readable project text is processed in the browser. The app stores only the resulting evidence record, scores and file names in local storage; it does not store the uploaded file contents.
