# Cubi colour palette

The interface uses a light, high-contrast palette designed for clear forms, cards and status labels.

- Background: `#F7F8F4`
- Surface: `#FFFFFF`
- Primary text: `#17211B`
- Secondary text: `#526158`
- Primary green: `#176B4D`
- Primary hover: `#11573E`
- Secondary blue: `#295F8A`
- Accent gold: `#E4A11B`
- Border: `#CDD6CF`
- Error: `#B63A3A`

The semantic OKLCH theme variables are defined in `src/styles.css`.
